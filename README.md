# Valoura

Valoura is a full-stack web application for discovering vendors, checking availability, submitting booking requests, managing reservations, and handling payments.

## Project structure

* `apps/web` — Next.js web application
* `apps/api` — Express API
* `packages` — Shared packages and contracts
* `docs` — Project planning and implementation documentation
* `.github` — GitHub issue, pull request, and workflow configuration

## Development

This project uses:

* Next.js
* React
* TypeScript
* Tailwind CSS
* Express
* npm workspaces

See the documentation in `docs/` for the project implementation workflow and MVP plan.
